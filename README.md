Датасет IT-вакансий с hh.ru, собранный самостоятельно. Домашнее задание 1.

## Как собирались данные

Скрипт `scraper/collect_hh.js` запускается в консоли браузера на странице hh.ru.
Он проходит по страницам поиска (100 вакансий на странице, до 10 страниц на запрос),
достаёт из каждой страницы встроенный JSON с результатами поиска и собирает таблицу.
Открытый API `api.hh.ru` на анонимные запросы отвечает `forbidden`, поэтому данные
берутся со страниц сайта. Подробная инструкция по запуску есть в начале скрипта.

## Что в данных "грязного"

- зарплата указана только примерно в 37% вакансий, `salary_to` пропущен в 79%;
- зарплаты в разных валютах (RUR, USD, EUR, BYR), с разным налоговым режимом (`salary_gross`) и за разный период (`salary_mode`: месяц, час, смена, услуга). Поэтому маленькие значения вроде 100 или 800 это суммы в долларах или оплата за услугу, а не месячная зарплата в рублях: перед анализом зарплаты нужно привести к одной валюте и периоду;
- рейтинг работодателя есть только у 56% вакансий;
- метро и координаты заполнены только когда работодатель указал адрес с метро: даже в Москве их нет у 39% вакансий;
- у анонимных работодателей нет `employer_id`, а название заменено описанием вроде "Производственная компания";
- в названиях встречаются HTML-сущности (`&amp;` вместо `&`);
- несколько колонок хранят список значений в одной строке через `|`;
- дубли по смыслу: 246 пар "название + работодатель" опубликованы в нескольких городах под разными ID.

## Идеи для анализа и моделей

- предсказание зарплаты по опыту, городу, стеку и формату работы (регрессия);
- от чего зависит число откликов на вакансию;
- доля удалённой работы по направлениям и городам;
- сравнение IT-аккредитованных компаний с остальными.
